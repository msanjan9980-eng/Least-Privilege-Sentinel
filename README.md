Least Privilege Sentinel is an AI powered Identity and Access Management review agent that identifies excessive, unused, and risky permissions. It autonomously discovers identities, retrieves permission and usage data, resolves effective permissions, analyzes dormancy and blast radius, and generates a least privilege remediation proposal. The agent writes and executes analysis code in a sandbox, presents evidence and a proposed action to a human, and pauses at a structural approval gate before any irreversible change. After approval, it executes the action, verifies the result, and records the complete decision in an audit trail.

AI assistants and coding tools used during development: ChatGPT, GitHub Copilot, and TrueForge AI Agent tooling.

The project architecture, implementation, security model, agent workflow, sandbox execution, and human approval mechanism are documented in the repository README.
